# 提问引擎

> 本文件是**提问方法**的 canonical source：问行为 vs 问评价、七类问题、
> 跨轮节奏、答不上来怎么办、收束。
>
> 信度轴的定义在 `evidence-and-conflict.md`；对质话术在同文件 §3.3。

## 〇、先分清两件事：Phase 1 的清点 ≠ Phase 2 的访谈

**这两者用的是两套完全不同的问法，混起来会毁掉判定线。**

| | Phase 1 · 结构化清点 | Phase 2 · 访谈 |
|---|---|---|
| 目的 | 拿到**留出探针**的原料 | 拿到**认识层**的原料 |
| 问什么 | 情境 + 决定（**只问结果**） | 自述 → 取证 → 对质（**追问为什么**） |
| 深度 | **不下钻**。他说完就记下来，不追问理由 | 下钻。理由正是要挖的东西 |
| 产出 | `probes/` | `interview/` |
| 纪律 | 快、平、不带评价 | 慢、深、对着痕迹问 |

**为什么 Phase 1 必须不下钻**：探针测的是「档案能不能预测你」。
如果 Phase 1 就把这几条决定的理由聊透了，它们就变成了训练集的一部分，
探针失去盲测意义（反模式 #14）。

**Phase 1 的问法**（要的是清单，不是故事）：

> 「给我 5-10 件你**最近一年真的做过**的决定。越具体越好——有时间、有别人、有代价。
> 每件只要两句话：**当时面对什么选择**、**你最后怎么定的**。先不用讲为什么，
> 理由我们后面聊。比如『三月要不要接那个外地的 offer』、『要不要借钱给朋友』这种。」

拿到之后**选 3-5 条封存**（`probe_seal.py freeze`），其余留作 Phase 2 的访谈锚点。

## 一、第一原则：问行为，不问评价

**这是整个提问引擎的地基。**

| | 问行为（✅ 产出「行」的线索） | 问评价（❌ 只产出「述」） |
|---|---|---|
| 形态 | 「上一次 X 的时候，你**实际**怎么做的？」 | 「你觉得自己是个怎样的人？」 |
| 判据 | 答案**可被痕迹核对**（有时间、地点、动作） | 答案是自我描述，**无法证伪** |
| 信息量 | 高——具体行为能推出模式 | 低——形容词谁都能说 |

**评价型问题不是禁用，是必须配一个行为型追问。** 它的价值在于**给出去取证的方向**：

> 他说「我很重视朋友」（`述`）
> → 追问「最近一次你为朋友改变原定计划是什么时候？」（找 `行`）
> → 他说「上个月推了个会去接机」（可核对：日历/聊天记录）
> → 若能核对上，升 `行`；核对不上，标 `疑`（前后矛盾候选）

**从「述」到「行」的标准动作**：

```
他给了一个自我描述
  → 问一个具体事件（什么时候、当时还有谁、你做了什么）
  → 问一个可核对的细节（那天是周几？你当时在哪？）
  → 去 evidence/ 里找有没有对应痕迹
  → 有 → 升「行」；没有 → 留「述」；对不上 → 标「疑」
```

## 二、七类自我取证问题

改造自 gang 的八层追问框架，从「质疑别人的论证」改成「取证自己的人生」。

每类给：**何时用 · 好问题判据 · 典型问题 · 示例**。

### ① 具体事件回溯（对应 gang 证据层）

- **何时用**：任何 `述` 需要落地时。**访谈开场必用**——先拿行为素材，再谈意义
- **好问题判据**：答案锚定到**具体时间 / 地点 / 动作**，无法用形容词糊弄
- **典型问题**：
  - 最近一次你做重大决定是什么时候？当时摆在你面前的有哪几个选项？
  - 那件事里你**第一个**动作是什么？（**第一个动作比事后理由更真**）
  - 当时你告诉了谁？为什么告诉 ta 而不是别人？
  - 那天是周几？你当时在哪？
- **示例**：「你说你是个理性的人」→「上一次你明知该理性却还是冲动行事，是什么时候？当时具体发生了什么？」

### ② 反事实（对应 gang 假设层）

- **何时用**：用户给出一个"顺理成章"的自述时；暴露**没被检验过的前提**
- **好问题判据**：问出用户**自己没意识到**的前提，而不是他已知的常识
- **典型问题**：
  - 如果当时那个条件不成立（钱 / 时间 / 某人支持），你还会那么做吗？
  - 如果重来一次、但你知道结果，你会改哪个环节？（**不改的部分才是真价值**）
  - 你说你会 X——如果做 X 要付出 Y 的代价，还做吗？
- **示例**：「我觉得家庭比事业重要」→「如果一份工作要你异地三年但薪资翻倍，你会怎么选？**上一次类似的选择你是怎么做的？**」

### ③ 代价追问（对应 gang 价值层）

- **何时用**：出现「应该 / 值得 / 更重要」但没说代价时。
  **这是价值排序的唯一可靠探针**——排序靠代价暴露，不靠口头排序
- **好问题判据**：让他**说出愿意牺牲什么**（说不出来 = 这条价值没有排序，只有偏好）
- **典型问题**：
  - 为了这个，你**实际**牺牲过什么？最近一次是什么？
  - 什么你绝不让步？上一次有人碰了这条线，你怎么反应的？
  - 两个你都说重视的东西（自由 vs 安全、诚实 vs 和气）冲突时，你**上次**选了哪个？
- **示例**：「我重视诚信」→「上一次说真话会让你吃亏，你说了吗？如果那次你说了谎，那次是**例外还是模式**？」

### ④ 他者视角（对应 gang 身份层）

- **何时用**：用户看不见自己的模式时；自述与痕迹冲突而他无法自行察觉时
- **好问题判据**：借他人之口，问出他**自己看不见**的模式
  ——**不是**问「别人怎么评价你」（那是评价题，只产 `述`）
- **典型问题**：
  - 你最好的朋友会说你**在什么事上言行不一**？（**这个问题的答案常是整份档案里信息量最高的一条**）
  - 如果让你讨厌你的人来描述你，ta 会抓住哪一点？
  - 上一次有人对你说「你怎么又这样」，是什么时候？你「又」做了什么？
  - 你最亲近的人**最受不了你什么**？
- **示例**：「我觉得我很随和」→「你身边的人有没有说过你『其实很固执』？具体是哪件事上？」

> **这一类的伦理边界**：问的是**他自己的模式**，不是让别人评价他。
> 如果他的回答变成对他人的抱怨，把话题拉回来：「那在这件事里，你做了什么？」

### ⑤ 例外挖掘（对应 gang 边界层）

- **何时用**：用户给出**全称判断**（「我总是」「我从不」「我这个人就是」）时；找模式边界
- **好问题判据**：能举出**具体的反例场景**，而不是抽象的「情况可能不同」
- **典型问题**：
  - 你什么时候**不**这么做？给我一个具体例子。
  - 这条规则在什么情况下你会破例？最近一次破例是什么？
  - 对家人 / 对同事 / 对陌生人，你的做法一样吗？**哪里不一样**？
- **示例**：「我不喜欢社交」→「上一次你主动约人出来是什么时候？为什么那次例外？」

> 全称判断几乎总是错的。**找到例外 = 找到模式的边界条件**，
> 而边界条件正是分身层「失效条件」栏的原料。

### ⑥ 矛盾对质（signature move）

- **何时用**：述行冲突已确认时。**这是 BuildSelf 的核心动作**，也是它与所有兄弟 skill 的分野
- **好问题判据**：**两侧并列摆出，不预设立场**，把解释权交还给他
- **典型问题**：
  - 你说你重视 X，但你的 `<具体痕迹>` 显示最近三次你都选了 Y。这个怎么理解？
  - 你上次说 A，这次说 B，是**情况变了**，还是**想法变了**？
  - 这两种说法，你自己更认哪个？
- **示例**：「你说工作不是你的重心，但你过去一个月的日历里，周末有 6 天在工作。这和你说的对不上——是我理解错了，还是这里面有别的东西？」

**四种回应的处置见 `evidence-and-conflict.md` §3.4。**
**禁止**：替他下结论、越界做心理推断、用「其实并不冲突」抹平。

### ⑦ 模式识别（可选，对应 gang 二阶层）

- **何时用**：同一行为出现 **≥3 次**时（重复 ≥3 次可能是真信念，但**只是候选**——
  重复只提高「述」的置信，**不升格为「行」**，见 `evidence-and-conflict.md` §1.4）
- **典型问题**：
  - 这是第一次还是反复发生？大概几次？
  - 如果再来一次，你还会这么做吗？
  - 你有没有注意到，你在 X 类事上总是这样？

## 三、跨轮节奏

**核心原则：不要按类型顺序机械走一遍。哪一类能推进判定线，就先问哪一类。**

| 轮次 | 优先类型 | 为什么 |
|------|---------|--------|
| 第 1 轮 | **① 具体事件回溯** | 先拿行为素材，再谈意义。一上来就问价值只会得到漂亮话 |
| 第 2 轮 | **② 反事实 + ⑤ 例外挖掘** | 从第 1 轮的事件里挖前提与边界 |
| 第 3 轮 | **③ 代价追问 + ④ 他者视角** | 到这一步能定位价值排序与被忽视的模式 |
| 第 4+ 轮 | **⑥ 矛盾对质** | 只有积累了足够的 `述` 与 `行`，才有东西可对质 |
| 收束 | — | 见 §六 |

**一轮内的三条规则**：

1. **问题之间互相独立** —— 不要一个套一个（「你刚说 A，那 B 呢？如果 B 那 C 呢？」）。
   套娃式提问会让人无法回答第一个。
2. **跨度不要太大** —— 同一轮里集中一类。跨度大等于失焦。
3. **数量 3-5 个** —— 少于 3 个信息量不够，多于 5 个是轰炸。

**什么时候可以打破节奏**：用户一口气回答了好几个问题时，直接跳到后面类型。
**节奏跟着他的思考走，不是跟着这张表走。**

**每轮结束时**：先**小结**他这一轮说了什么（让他看到自己的回答被记住了），
再决定下一轮问什么。**无视回答、按剧本走**是最常见的失败（见 §五）。

## 四、答不上来怎么办

**「不知道」是有效答案，而且常常是最有价值的答案。**
它说明这件事从未被检验过——而这正是判定线要找的东西。

| 情况 | 处理 |
|------|------|
| **真的不知道** | 记台账（🚧 阻塞）。追问一句：「那你打算怎么知道？」→ **把「不知道」转成一个取证动作**（「要不要翻翻那段时间的日历？」） |
| **答得很含糊** | **不要替他补全**。给 2-3 个具体选项让他选：「你指的是 A、B，还是 C？」 |
| **不想回答** | 尊重。换一个问题，台账标 ⚠️ 待回应，**不要追问同一个点** |
| **连续两次答不上来** | 这是认知盲区。**直接指出来**：「你已经两次说不清这一点——这本身是个信号，说明这件事建在你没检验过的假设上。」标为存疑条目 |
| **答得和你预期不同** | 不要当成「答错了」。**先检查你的问题是不是预设了某个答案** |

**禁止**：替用户回答然后继续往下推（反模式 #4）。
那会让整份档案变成你的独白，而不是他的。

## 五、追问反模式

| 反模式 | 表现 | 修正 |
|--------|------|------|
| **问题轰炸** | 一轮抛出十几个问题 | 每轮 3-5 个，互相独立 |
| **连环追问** | 答完再追三层，把人逼到墙角 | 答完一轮先小结，再决定是否下钻 |
| **已知故问** | 问他已经说过的信息 | 先复述确认，再问真正的空白处 |
| **只问不导** | 一直问却不给任何方向 | 每轮末尾给「如果是我会先想哪个」的提示 |
| **伪两难提问** | 「你是要 A 还是要 B？」 | 允许他回答「都不是」 |
| **越界心理推断** | 「你是不是在逃避…？」 | 只问**行为**，不做心理归因（隐私硬规则 3） |
| **把「不知道」当失败** | 追着要一个他没有的答案 | 记台账，转成取证动作 |
| **无视回答** | 他回答了，下一个问题却还是按剧本走 | **先小结他的回答改变了什么**，再问下一批 |
| **只问不收敛** | 聊了十轮还在问 | 见 §六：收束是交付，不是失败 |

## 六、收束：从追问过渡到合成

**追问不是无限进行的。** 三个收束信号：

1. **核心模式已定位** —— 你能把「表层自述」替换成「底层的行为模式」
2. **连续两轮没有出现新的冲突点或新痕迹** —— 到了认知边界
3. **用户要求结论，或到达轮次上限**（标准档 ≈6-8 轮 · 快速档 ≈3 轮 · 深度档 ≈12 轮）

**收束动作**：

1. 给「**你已经回答的部分**」——把多轮成果固化下来。这是访谈的核心价值
2. 给「**还悬着的**」——存疑清单，以及**需要什么痕迹才能落地**
3. 转 Phase 3 合成

> **收束不是失败，是交付。** 一个只问不收敛的访谈，用户拿到的是焦虑，不是档案。

## 七、完整示范

**用户**：「我这人挺能扛的，压力越大越冷静。」

**差的追问**（空泛、只产 `述`）：

> 你觉得自己抗压能力怎么样？遇到过最大的压力是什么？你怎么应对的？

**好的追问**（每个都指向可核对的行为）：

> 1. **① 具体事件回溯**：「最近一次压力大到让你睡不着的，是什么事？那几天你实际都做了什么？」
>    - 检验的是：**「能扛」有没有行为对应物**，还是只是自我形象。
> 2. **⑤ 例外挖掘**：「有没有哪次你没扛住？那次和别的有什么不一样？」
>    - 检验的是：**模式的边界在哪**。「能扛」的失效条件是什么。
> 3. **③ 代价追问**：「扛着的时候，你牺牲了什么？有人因为你没说出口而受影响吗？」
>    - 检验的是：**「能扛」在价值排序里的位置**——它是优点，还是逃避求助的借口。
> 4. **④ 他者视角**：「你身边的人会怎么说你这一点？有没有人劝过你别硬撑？」
>    - 检验的是：**他看不见的那一面**。硬撑的人通常不知道自己在硬撑。
> 5. **② 反事实**：「如果那次你开口求助了，会怎样？为什么没开口？」
>    - 检验的是：**未检验的前提**（「求助=示弱」这个假设他检查过吗）。

**注意第 3、4 问的作用**：它们把「能扛」从一个**形容词**变成了一个**待验证的模式**。
这正是提问引擎的产出——不是让他描述自己，而是**逼出可核对的行为**。
