# 维度体系：核心六维 + 扩展维度

> 正文段的**标题与顺序**在 `self-archive-format.md` §2.4 定义；
> 维度底稿 `dims/*.md` 的形状在同文件 §2.5。
> 本文件讲三件事：**核心六维**（默认透镜）、**扩展维度**（这个人独有的领域）、
> 以及**每一段怎么写才算合格**。

---

## 一、核心六维：覆盖透镜，不是章节

六维不是 `SELF.md` 的章节——它们是**取证时的默认覆盖清单**：
每拿到一份痕迹、每问完一轮，回来看这六格哪格还是空的。

维度名写入 `SELF.md` frontmatter 的 `dimensions`，也是
`manifest.evidence[].dimensions` 与访谈台账 `dimensions` 的取值域。

| 编号 | 维度 | 覆盖什么 | 主要证据来源 | 常见陷阱 |
|------|------|---------|-------------|---------|
| 01 | **身份** | 他怎么看自己是谁：角色、坐标系、自我叙事 | 自述 + `evidence/notes/` | ❌ 写成履历（「XX，1990 年生」）。身份是**他用来解释自己的那个故事**，不是简历 |
| 02 | **决策** | 可追溯的真实选择：下注、拒绝、退出、时间与金钱分配 | `evidence/calendar/` `evidence/transactions/` `evidence/decisions/` | ❌ 结果论——用事后成败反推决策质量；❌ 只收成功案例，丢掉后悔与失败 |
| 03 | **表达** | 语言表层：句法、修辞、口癖、幽默方式 | `evidence/chat/` `evidence/notes/` | ❌ 用「幽默风趣」这类**无法证伪**的形容词收尾 |
| 04 | **关系** | 他怎么对待不同的人：家人/同事/陌生人/对手 | `evidence/chat/` `evidence/others/` | ❌ 只收他对自己的描述（「我很重感情」）。关系必须从**双向痕迹**里取 |
| 05 | **价值** | 冲突时的排序：优先牺牲什么、保住什么 | **主要靠访谈取证**，用 `evidence/calendar/` 校验 | ❌ 并列罗列（「既重视 A 又重视 B」）——**没有排序就没有价值** |
| 06 | **时间线** | 立场与模式**改变**的节点与触发事件 | `evidence/notes/` + 访谈 | ❌ 把生平流水账当时间线。只保留「与立场变化挂钩」的事件 |

**核心六维须互斥、穷尽、可并行。** 一条素材可以覆盖多个维度（在
`manifest.evidence[].dimensions` 里列多个），但**归类时不能既算 A 又算 B 而说不清**。

### 1.1 六维是默认，不是必须填满的格子

**没覆盖到的核心维度不建文件，但要进 `存疑与缺口`。**

| 情形 | 怎么做 |
|------|--------|
| 覆盖到了，有东西写 | 建 `dims/0N-<slug>.md`，维度名写进 `dimensions` |
| 没覆盖到 | **不建文件**，在 `## 存疑与缺口` 里写「这一维没有素材 + 需要什么才能补」 |
| 只覆盖了一部分 | 建文件，把缺的部分写进该文件的 `## 还没查到`（标 `（可补）`/`（待事件）`） |

**六维里有一格全空是常见的**——不用为了凑满而编（反模式 #4）。
但**空着不写 ≠ 不存在**：不写进存疑段，读的人会以为「看过了，没事」，
那是把「没看」伪装成「没有」。

## 二、扩展维度：这个人独有的领域

**核心六维是给所有人的默认透镜。但每个人的情况都不一样**——
有的人所有重要决定都围绕「钱」，有的人有一整套极完整的「技术品味」，
有的人的生活重心是「育儿」，六维里装不下。

**这就是扩展维度**：编号从 `07` 起，与核心六维**同构**
（一样是 `dims/NN-<slug>.md`、一样的 `## 证据` + `## 还没查到` 两段）。

### 2.1 什么时候建（判据只有一条）

> **这个领域里，有没有一个只有他才会做的选择？**

| 建 | 不建 |
|---|---|
| 「金钱」——他为了不陪客户喝酒，放弃了涨薪 20% 的调动 | 「爱好」——「他喜欢看电影」，谁都能填 |
| 「技术品味」——他宁可重写也不接受一个能跑但脏的方案 | 「性格」——那是特质标签，不可证伪（反模式 #3） |
| 「育儿」——他为了接送孩子把会议全排在上午 | 「生活习惯」——没有「只有他才会做的选择」 |

**判据和核心六维的「常见陷阱」是同一把尺**：能不能落到
「**情境 → 行为**」上。落不到 → 不建，那是装饰（反模式 #31）。

### 2.2 怎么建

```
1. 在 manifest.dimensions[] 里声明
   {"id": "07", "name": "金钱", "kind": "extended", "file": "07-money.md",
    "why": "为什么六维装不下它——须写清", "opened": "2026-10-15"}
2. 建 dims/07-money.md（形状见 self-archive-format.md §2.5.1）
3. 把「金钱」加进 SELF.md frontmatter 的 dimensions（**核心六维之后**）
4. 受影响的 evidence / 访谈台账回填 dimensions
```

**`why` 栏答不出 → 不该建。** 它是这个机制唯一的防灌水闸门。

### 2.3 上限 5 个

多于 5 个扩展维度通常说明没提炼——**领域不是越多越好，
是越「只有他才会这样」越好**。6 个以上的「独有领域」，
多半是把核心六维拆细了（那应该在核心维度内部写细，不是新开格子）。

**扩展维度通常在深化循环里被发现**（`deepening-engine.md` §5.2）——
因为只有把六维都取过一遍证，才看得出哪一块是六维装不下的。

## 三、各段怎么写才算合格

### 3.1 `## 一句话`

一段话定位：**用他自己的坐标系**，不用履历腔。

| | 写法 |
|---|---|
| ❌ | 「张三，1990 年生，某公司技术总监，性格沉稳。」 |
| ✅ | 「一个把『不欠人情』看得比升职更重的人——他为此在三年里推掉了两次管理岗。」 |

判据：**这段话里有没有一个只有他才会做的选择？** 没有就说明还没提炼出来。

### 3.2 `## 核心骨架`（3-10 条）

**判定线的承重墙。** 探针盲测必须能指回这里的某一条——指不回去，说明骨架没覆盖到。

| 要求 | 判据 |
|------|------|
| 每条带信度标记 | `（行 · evidence/...）` / `（述 · interview/...）` / `（推 · 由 #3 与 #7 推出）` |
| 每条带出处指针 | 没有指针就无法回查，溯源 S 轴测的就是这个 |
| **`行` 占比 ≥ 30%** | 低于此，档案只是「自述誊清稿」 |
| **`推` 占比 ≤ 20%** | 越过这条线，档案推的是蒸馏者自己 |
| 3-10 条 | 少于 3 没提炼，多于 10 没取舍 |
| **可预测** | 每条自问：**拿它去预测一件档案没提过的事，能推出什么？** 答不出 → 这条不是骨架，是废话 |

**骨架条目的写法**：必须是**「情境 → 行为」**，不是特质形容词。

| | 写法 |
|---|---|
| ❌ | 「他很固执。」（不可证伪，预测不了任何具体决定） |
| ✅ | 「被明确告知代价后仍不改主意——三年内两次拒绝管理岗，第二次被告知『不接受就离职』（行 · evidence/decisions/2025-08.md）」 |

### 3.3 `## 心智模型`（3-12 条）

每条四件套，**缺一不可**：

```markdown
### <模型名>
- **一句话**：他怎么看这件事
- **证据**：≥2 个**不同场景**（带信度标记）
- **应用**：能推出什么新判断
- **局限**：什么情况下失效
```

**三重验证**（每条模型都要过）：

| 验证 | 判据 | 不过说明 |
|------|------|---------|
| **跨场景复现** | 至少 2 个**不同领域**的场景都能看到它 | 只在一个场景出现 → 那是习惯，不是模型 |
| **生成力** | 能推出材料里没写过的具体判断 | 推不出 → 那是复述，不是模型 |
| **排他性** | 换一个人，这个模型不成立 | 谁都能套 → 那是通用智慧，不是他的 |

❌ **把「局限」写成「需结合实际情况判断」这类空话**——那等于没写局限。
✅ 局限要具体到「**在什么情境下他会判断失误**」。

### 3.4 `## 价值排序`

**必须给出排序，不允许并列罗列。**

❌「他既重视自由，又重视稳定。」——无信息量。
✅「自由与稳定冲突时他选自由，代价是接受了收入的不稳定。」

**排序靠代价暴露，不靠口头排序。** 写法：

```markdown
**排序**：<A> > <B> > <C>
**依据**：为 A 牺牲过 <具体的 B>（行 · evidence/...）
**反模式**：他明确反对的行为与论证方式
```

**本质性张力（`CONFLICTS.md` 里分类为「本质性」的）必须在这里落地**——
它们是价值排序的直接证据，不是附录。

### 3.5 `## 表达特征`

**必须量化。形容词一律不合格**（不可证伪的描述，反模式 #3 的同族）。

| 项 | 定义 | 记法 |
|----|------|------|
| **句式指纹** | 可统计的句法特征 | 平均句长 / 疑问句占比 / 类比密度（每千字个数）/ 转折词偏好 |
| **风格标签轴** | 4 组对立轴上的取值 | 冷↔热 / 抽象↔具象 / 断言↔试探 / 书面↔口语 |
| **口癖与禁忌词** | 高频口癖（白名单）与从不使用的词（黑名单） | 各列 5-10 条，**附出现频次** |

**量化方法**：直接复用「重复次数是最强的去水信号」——口癖 = 高频重复项；
风格标签 = 对**全部素材**的统计倾向，**不是挑最精彩的一段**。

**样本 < 10 条时标注「样本不足，风格标签为推测」**（标 `推`）。

**注意**：聊天记录是**对特定人表演的**。同一个人的工作群语气和家庭群语气可能完全不同——
若差异显著，**分场景写**，不要平均成一个"风格"。

### 3.6 `## 冲突与张力`

**只写指针。** 冲突的唯一定义处在 `CONFLICTS.md`（见 `evidence-and-conflict.md` §三）。

要么列出冲突编号（`见 CONFLICTS.md 的 C1、C3`），
要么声明「未发现述行冲突」并**交代核查范围**（≥20 字，说清比对了哪些痕迹与哪几条自述）。

### 3.7 `## 存疑与缺口`

**每一条带「疑」标记的条目都必须在这里出现**，或说明为什么不在。

写法：**缺什么 + 需要什么才能补上**。

| | 写法 |
|---|---|
| ❌ | 「有些地方不确定。」 |
| ✅ | 「长期职业取向未定——他的自述在『想做技术』与『想带团队』之间摇摆（第 3、6 轮），且近两年的日历里两类投入各占一半。需要一次真实的二选一才能定。」 |

**「没有缺口」本身就是可疑的**——写 `null` 表示未判定，不表示没有。

### 3.8 `## 变更记录`

追加式，**只增不改**。

| 版本 | 日期 | 改了什么 | 触发 |
|------|------|---------|------|

**被推翻的旧条目保留并标注「已被 X 修正」**，不要静默删除（反模式 #11 的兄弟：
演化轨迹本身是信息）。

## 四、质检清单（`self_check.py` 之外的语义检查）

结构检查过不了的这里不重复。以下是**结构合法但内容不合格**的常见形态，
由评分 agent 在 Phase 5 核：

- [ ] 未建的核心维度都进了 `## 存疑与缺口`（**空着不写 ≠ 不存在**——那是「没看」不是「没有」）？
- [ ] 扩展维度都答得出 `why`（「六维装不下、且只有他才会这样」），且不超过 5 个？
- [ ] 核心骨架每条的「可预测性」自问过吗？（拿它推一件没提过的事）
- [ ] 心智模型 3-12 条，每条过了**三重验证**且**局限写得具体**？（**闸门是验证不是条数**）
- [ ] 价值排序给了**排序**而不是并列？本质性张力都在这里落地了？
- [ ] 表达特征三项都是**可计数量化**，无形容词凑数？
- [ ] 存疑段的每条都说了**「需要什么才能补上」**，而不只是「不知道」？
- [ ] 时间线里至少有**一个「改变」的节点**？全篇立场不变通常意味着素材太薄？
- [ ] `## 一句话` 里有一个**只有他才会做的选择**？
