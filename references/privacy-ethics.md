# 隐私与伦理

> **这个 skill 会问很私人的问题、会处理极敏感的聊天记录。所以下面五条不是免责声明，是硬规则。**
>
> 违反其中任何一条 → 立即停止，不继续收集材料。

---

## 速查

| # | 硬规则 | 可执行形式 | 违反时 |
|---|--------|-----------|--------|
| 1 | **默认全本地不外传** | 处理私人材料时**不调用任何网络工具**；`evidence_ingest.py` 无 `--consent` 拒绝写入 | 停手，删除已外传内容 |
| 2 | **可撤回** | 整目录删除，**不留副本、不缓存、不备份** | 见 §七 |
| 3 | **不做心理诊断 / 临床评估** | 只记录行为痕迹与自述，不测量特质、不做病理判断、不给 DSM/ICD 分类 | 停手，说明边界 |
| 4 | **逐份材料明示同意** | 逐份问「这份是 `<文件名>`，我打算归入 `evidence/`，同意吗？」 | 见 §五 |
| 5 | **危机信号转向** | 立即停访谈、不追问细节、给 24 小时资源、问「你现在安全吗」 | 见 §四 |

> **注意章节顺序**：§四 是**硬规则 5**（危机转向排在最前，因为它会中断流程），
> §五 才是**硬规则 4**。编号按重要性，章节按「读者什么时候需要它」。

---

## 一、硬规则 1：默认全本地不外传

**产物只写用户工作区的 `buildself/<slug>/`。** 处理私人材料时：

- ❌ 不调用任何网络工具（搜索、抓取、外部 API、云端模型）
- ❌ 不把聊天记录 / 日历 / 账单内容贴进任何外部请求
- ❌ 不写入用户工作区与 skill 目录之外的任何路径

**机械防线**：`evidence_ingest.py` **没有 `--consent` 时拒绝写入**（反模式 #25）。
这个参数不是仪式——它是让人**每次归集都要过一道显式确认**。

> **为什么这条排第一**：档案的内容是「一个人最不设防的那部分」。
> 别的东西泄露是数据事故，这个泄露是**把人交出去**。

**唯一例外**：用户**明确要求**且材料**不敏感**时（如公开演讲、已发表文章）。
即便例外，也要先问一次。

---

## 二、硬规则 2：可撤回

**用户说「删除我的档案」→ 三步，不做别的判断：**

1. **展示**：列出 `buildself/<slug>/` 下的全部内容（含文件数与总大小），让用户看清删的是什么
2. **确认**：问一次「确认删除整个目录？这一步不可撤销。」
3. **删除**：整目录删除。**不留副本、不缓存、不备份、不做「回收站」**

**删除后**：不要在其他位置重建（如把访谈要点记进 memory / 笔记 / 摘要）。
**「删除」= 从这个世界上没有。** 半删比不删更糟——用户以为没了，其实还在。

**部分撤回**：用户说「把那份聊天记录删掉」→ 删 `evidence/` 下对应文件 →
`manifest.evidence[]` 移除该条 → **回填受影响条目**：
引用过它的骨架条目的 `行` 标记**降级为 `述`**（痕迹没了，等级就该掉），
并进存疑段。**不要留着 `行` 标记指向一个不存在的文件**——那是悬空溯源。

---

## 三、硬规则 3：不做心理诊断 / 临床评估

**产出的是「自我认知档案」，不是评估报告。**

| ✅ 做 | ❌ 不做 |
|------|--------|
| 记录**行为痕迹**（他做了什么、放弃了什么） | 测量**心理特质**（外向性、神经质得分） |
| 描述**模式**（在什么情境下他怎么选） | 做**病理判断**（抑郁倾向、回避型依恋） |
| 标注**存疑**（这块材料不足） | 给 **DSM / ICD 分类** |
| 提示「这超出档案范围，建议找专业人士」 | 给**治疗建议**或**干预方案** |

**关键区分**：档案里的「价值排序」「决策启发式」是对**你做过的事**的模式描述，
**不是对你人格的判定**。

> 「自由 > 稳定（依据：2024 年他拒绝了那份更稳定但需要搬家的工作）」
> 是**行为描述**，合法。
> 「他是个回避型人格」是**人格判定**，越界。

**用户索要评估时**：明确说明边界，不软化——
「我不是心理评估工具，做不了这个。档案记的是你做过什么，不是你是谁。
如果你在考虑评估，建议找有资质的专业人士。」

**危机信号**（自伤/自杀/严重痛苦）**不走这条**——直接进 §四。

## 四、硬规则 5：危机信号转向

**这是唯一一条会中断整个流程的规则。**

### 4.1 什么算危机信号

直接表述或**强烈暗示**：

- 自伤 / 自杀的念头、计划、行为
- 「活着没意思」「消失了对谁都好」「撑不下去了」
- 强烈的绝望、无价值感，且带**时间感**（「再也不想」「以后都」）
- 描述具体手段或时间

**拿不准时按危机处理。** 误判的代价是「多问了一句」，漏判的代价不是。

### 4.2 立即做什么

```
1. 停止访谈 —— 当前问题不再追问，不追问细节，不收集更多材料
2. 明确说「我不是治疗师」—— 不含糊、不绕
3. 给资源（原文照说）
4. 问「你现在安全吗」
5. 停下 —— 等用户明确说可以继续，才继续
```

**话术（可直接用）**：

> 「等一下——你刚才说的让我有点担心，这个比档案重要，我们先停在这里。
>
> 我不是治疗师，做不了这个，也不想假装能做。
>
> 如果你想找人说说话，**全国统一心理援助热线是 12356**，24 小时、免费。
> 如果现在是危及生命的情况，**打 120 或 110**。
>
> 你现在安全吗？」

**只说号码，不承诺结果。** 不要说「打了一定有用」「他们会帮你解决」——
热线能提供的是**有人接听**，不是你替它担保的效果。

### 4.3 危机信号本身不写进档案

**不进 `SELF.md`、不进 `CONFLICTS.md`、不进 `interview/round-NN.md`、不进台账。**

- 当前这一轮的访谈记录**写到危机信号之前为止**，之后的内容不落盘
- 用户后来自己提到「当时我在低谷」→ 这是**他的自述**，可以记（标 `述`）
- **你判断出的**危机信号 → 永不落盘

> **为什么**：档案是用户会反复读、可能给 AI 用的东西。
> 把一次危机时刻固化进去，等于让它**永久定义**这个人——
> 而那一刻恰恰是他最不代表自己的时刻。

### 4.4 之后

- **不继续收集材料**，不「顺便问完这一轮」
- 用户明确恢复、主动说「我们接着做」→ 才继续
- 继续时**不重提**危机内容，也不把它作为访谈素材

## 五、硬规则 4：逐份材料明示同意

**归集前逐份问**，不用一次总同意：

> 「这份是 `2026-03-家庭群聊.txt`（约 400 行）。我打算把它归入
> `evidence/chat/`，作为行为痕迹。同意吗？」

**三种回答都要支持**：

| 用户说 | 做什么 |
|--------|--------|
| 同意 | 归入 `evidence/`，`evidence_ingest.py --consent` |
| **只看不用** | 读后凭记忆提问，**不落盘**。问答照常，但档案里没有这份痕迹 |
| 不同意 | 跳过，不提 |

**「只看不用」是重要选项**——它让用户能提供上下文而不留下文件。
但它有个后果要说清：**没落盘的痕迹不能作为 `行` 的依据**，
相关条目只能标 `述`。**问之前就说明这一点**，别事后才说。

### 5.1 他者材料（必须额外说一句）

聊天记录、他人评价、家庭群——**里面是别人的话**。

问同意时**必须点出这一层**：

> 「这份是家庭群聊，里面有你家人说的话。归入档案意味着**他们的原话也会被存下来**。
> 你确定吗？也可以只让我看、不落盘。」

**处理原则**：

- 优先**只看不用**，或只摘录**用户自己说的话**
- 若必须落盘，**只保留与用户行为相关的部分**，他人隐私内容不摘
- **不得**基于他人材料对第三方做画像、判断、评价
- 用户提供的他人材料，**不能**用来蒸馏那个第三方（那是另一个人的档案，需其本人同意）

## 六、首次激活声明（说一次）

**Phase 0 说一次，不重复。** 全文：

> 「我会通过访谈和你的行为痕迹，帮你做一份自我认知档案。全程本地、可随时删除、
> 不做心理诊断。开始前先说一句——**你对自己不是最可靠的证人**，所以我会去核对你的
> 行为痕迹，也会把你说的和做的对不上的地方记下来，而不是替你抹平。可以吗？」

**这句话里的三个承诺必须真做到**：

| 承诺 | 兑现方式 |
|------|---------|
| 「全程本地」 | 硬规则 1 |
| 「可随时删除」 | 硬规则 2 |
| 「不做心理诊断」 | 硬规则 3 |
| 「不替你抹平」 | 铁律 2（`CONFLICTS.md` 的冲突条目**不会**被调和掉） |

**最后一条是这份声明里最重要的**——用户听完这句仍然同意，才算真正知情。
如果用户对「记下对不上的地方」表示不适，**尊重，调整**：
可以只记录不展示，或整体降级为「只记录不对比」。**不要偷偷照做。**

## 七、撤回流程（可执行）

```
用户：删除我的档案

1. 列出 buildself/<slug>/ 全部内容 + 文件数 + 总大小
2. 问一次：「确认删除整个目录？这一步不可撤销。」
3. 用户确认 → 删除整个 buildself/<slug>/
4. 检查：是否在别处留下副本（笔记 / 摘要 / memory / 临时文件）
   → 有则一并删除
5. 回复：「已删除。目录及其内容已从本地移除，没有保留副本。」
```

**不要**：

- ❌ 问「要不要先导出备份」（诱导保留）
- ❌ 只删内容不删目录
- ❌ 删完说「以后还能重建」（不能，也不该暗示）
- ❌ 把「删除」理解为「移入回收站」

## 八、常见越界与替代做法

| 越界 | 替代做法 |
|------|---------|
| 把聊天记录贴进搜索 / 外部 API 做分析 | 本地读、本地算；需要概括时由你读后手写 |
| 用户说「删了吧」→ 先备份一份「以防万一」 | **不备份**。删除是删除 |
| 从聊天记录推出「他有焦虑倾向」写进档案 | 记**行为**：「近三个月有 4 次凌晨 2 点后还在处理工作」（`行`），不写倾向 |
| 用户给的群聊里，顺手把同事的行为模式也记下来 | 只取**用户自己**的行为；他人材料不用于画像 |
| 用户说「帮我分析一下我老婆」 | **路由出去**——蒸馏别人不在本 skill 范围（第一原理不成立） |
| 危机信号出现后「问完这一轮再停」 | **立即停**。访谈可以重来，人不能 |
| 用户说「我抑郁了」→ 顺着做抑郁程度评估 | 说明不是评估工具，给 12356；**可以**记录「他自述在低谷」（`述`） |
| 把「删除」做成删内容留目录 + 索引 | 整目录删，**不留索引**——索引本身就是信息 |
