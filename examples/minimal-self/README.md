# 最小合法示例档案

> ⚠️ **这是虚构人物，不是真人的档案。** 用途是**对照「哪些是结构要求、哪些是质量要求」**——
> 它故意做得薄但合法：能过 12 项结构检查，但质量轴上拿不到高分。

## 这是什么

一份**自我认知档案**，由 `buildself` skill 产出。两层产物，同一个 ground truth：

| 层 | 文件 | 给谁看 |
|----|------|--------|
| **认识层** | `SELF.md`、`CONFLICTS.md` | **你自己**——「我是谁」 |
| **分身层** | `PRINCIPLES.md`、`DECISIONS.md`、`VOICE.md`、`BOUNDARIES.md` | **另一个 AI**——「遇到 X 我会怎么做」 |

`dims/` 是**取证底稿**，不是章节：它记「这一维查了什么、还缺什么」，`SELF.md` 的结论
从这里长出来。**底稿里可以有「这条痕迹还解释不通」，`SELF.md` 里不可以。**

## 怎么用

**自己读**：从 `SELF.md` 开始，然后**必读** `## 存疑与缺口` 与 `CONFLICTS.md`。
冲突段是整份档案信息量最高的地方——**读着不舒服的那段，才是能预测你的那段**。

**给 AI 用**：把 `SELF.md` + 分身层四文档一起喂给它。消费时有两条硬规则：

1. 按**骨架条目**作答——先指出依据的是哪一条，再给立场。
   **指不回去的答案不许说出口**：那用的是模型的常识，不是这份档案。
2. 问题落在 `## 存疑与缺口` 范围内 → **明确拒答**，不要硬答。

**下游产物要记 `slug` 与 `self_sha256`**（见 `manifest.json`），以便检测档案漂移。
档案是**只读输入**，不是可编辑的中间态：产物与档案不一致时，重新消费当前档案，
**不要改档案去迁就产物**。

## 这个示例**故意缺什么**

用来对照「结构合格 ≠ 质量合格」：

| 缺什么 | 后果 |
|--------|------|
| 素材只有 3 份、约 210 字 | 溯源轴（25 分）拿不到分——断言 diff 抽 6 条，能定位的很少 |
| **关系、时间线两维未建** | 覆盖等级停在「稀疏」；但两维都在存疑段里交代了，所以结构合法 |
| 只有 1 条冲突 | 诚实度轴（25 分）按比例给分，冲突少 = 分低 |
| 公理集 3 条，偏少 | 可执行性轴（20 分）的张力只有 1 对 |
| 表达特征样本不足 | 风格标签是推测（标了 `疑`） |

**但它的结构是合法的**：字段齐备、标记规范、探针封存完好、两层同源、维度三方对账一致。
这正是要说明的那句话——**过了 12 项结构检查只等于「值得花一次评分」。**

## 它自己列着「还没查到」

跑深化议程看这份档案下一轮该补什么：

```bash
python3 ../../scripts/self_gaps.py .
```

它会报覆盖等级（稀疏）并排出一份按**边际信息量**排序的议程：P0 那条未解决的冲突 →
P1 各个维度底稿里标了「（可补）」的缺口 → … 末尾单列**不可补的缺口**（标了「待事件」的）。

本示例有一条「待事件」缺口：**他面对亲人借钱会怎么反应**——只能等它真实发生。
**为它编内容是编造，不是丰富**，所以它留在那儿。详见
[`../../references/deepening-engine.md`](../../references/deepening-engine.md)。

## 怎么撤回

**整目录删除即可**，没有外部副本、没有缓存、没有备份：

```bash
rm -rf minimal-self/
```

档案默认全本地，不含任何外部引用。
