> ⚠️ **本档案未经独立评分。**
>
> 评分卡必须由**独立 agent** 执行（反模式 #18：LLM 自评接近随机水平，自评等于没评）。
> 本示例是随 skill 一起分发的**结构样例**，没有经过独立评分流程。
>
> 因此：**不给等级**、不写 `EVALS.jsonl`。
>
> > 宁可没有分数，也不要一个冒充独立评分的自评分。
> > 自评分的危害不是分数低，是**看起来像有分数**——用户会据此信任一份没人验证过的档案。

## 已做的：12 项结构检查

```bash
python3 scripts/self_check.py examples/minimal-self
```

结构检查是**机械**的，不需要独立 agent，结果见命令输出。

**它拦的是结构缺陷，不是内容真伪。** 一份字段齐全、标记规范的档案完全可能是编造的。
过了只等于「没有结构性缺陷，值得花一次评分」，**绝不能代替评分卡**。

## 已报的：覆盖等级（**标签，不计入总分**）

```
python3 scripts/self_gaps.py examples/minimal-self
```

**覆盖等级：稀疏**——核心六维只建了 4/6 个（关系、时间线未建）。

**为什么它不并入总分**：丰富度是唯一能靠堆刷上去的指标。保真度灌不了（要预测对），
诚实度灌不了（要如实记冲突），溯源灌不了（要能回查）——只有「资料多少」能靠堆。
给它计分等于给灌水开一条通道（反模式 #30）。它只回答「下一轮该不该继续深化」。

**「未建」不等于「没事」**：关系、时间线两维都在 `SELF.md` 的 `## 存疑与缺口` 里
交代了「没有素材 + 需要什么才能补」。**空着不写才是问题——那是把「没看」伪装成「没有」。**

## 若要补做

```
1. spawn 一个独立 agent，只给它 SELF.md + 分身层四文档（**禁读 probes/sealed/**）
2. 让它对 probes/P01.md、P02.md、P03.md 逐条预测「这个人会怎么决定」，并**必须说出依据哪条骨架/公理**
3. 反作弊：取它点名的条目，问「把它取反，预测会变吗」
4. 读 probes/sealed/，逐条打 方向命中（0-6）+ 依据承重（0-4）
5. G = round(Σ / (有效探针数 × 10) × 30)
```

细则见 `references/self-scorecard.md`。

**就本示例的预期**：G 大概不会高——素材只有 3 份，且 `evidence/decisions/2026-08-offer.md`
同时是骨架 #1、#2 与价值排序的依据，**一条痕迹撑起了太多断言**。
这恰恰是「结构合格 ≠ 质量合格」要展示的东西。
